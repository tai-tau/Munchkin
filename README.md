# איך מפעילים את המשחק

שלוש דרכים. **התחילו מהראשונה** — היא הכי קלה.

---

## דרך 1 — אחד מכם מריץ, כולם בזום

**הכי מהיר. עובד תוך חמש דקות.**

### מה צריך
מישהו אחד מכם שיתקין תוכנה בשם **Node.js**. חינם, התקנה רגילה של "הבא הבא סיום".

הורידו מ־nodejs.org, גרסת LTS.

### הפעלה

1. שמרו את התיקייה `game-server` על שולחן העבודה
2. פתחו אותה
3. **ווינדוס:** לחצו על שורת הכתובת למעלה, מחקו מה שכתוב, כתבו `cmd` ואנטר
   **מק:** לחצו ימני על התיקייה ← "New Terminal at Folder"
4. בחלון השחור שנפתח כתבו:

```
node server.js
```

5. יופיע: `http://localhost:3000`

### איך כולם נכנסים

**מי שמריץ** פותח את הקישור בדפדפן ומשחק.

**השאר** — שתפו מסך בזום ותנו לו להזיז בשבילכם. **או** עברו לדרך 2.

---

## דרך 2 — כולם מכל מקום, בלי התקנות

**אתם מעלים את המשחק לאינטרנט ומקבלים קישור שכולם נכנסים אליו.**

### עם Render (חינם)

1. היכנסו ל־render.com ופתחו חשבון
2. לחצו **New** ← **Web Service**
3. בחרו **Public Git repository** או העלו את התיקייה
4. בשדה **Start Command** כתבו: `node server.js`
5. לחצו **Create**

תוך כמה דקות תקבלו כתובת כמו `https://munchkin-xyz.onrender.com`.

**שלחו אותה בוואטסאפ. כל אחד פותח בטלפון או במחשב וזהו.**

### הערה
בגרסה החינמית השרת "נרדם" אחרי חוסר פעילות. **הכניסה הראשונה תיקח כחצי דקה**, ואז הכול מהיר.

## דרך 3 — ngrok

אם מישהו כבר מריץ לפי דרך 1 ואתם רוצים שכולם ייכנסו מרחוק בלי להעלות לאינטרנט:

1. הורידו ngrok מ־ngrok.com
2. הריצו: `ngrok http 3000`
3. תקבלו קישור זמני. שלחו לכולם

**הקישור מת כשסוגרים את החלון.** טוב לערב אחד.

# איך משחקים

**כל אחד נכנס, כותב שם, בוחר מין.** אחרי שכולם נכנסו — מישהו לוחץ **"משחק חדש"**.

## מה רואים

**למעלה — השולחן.** ארבעה כפתורים: פתח דלת, דלת ליד, שלוף אוצר, פנה שולחן. מתחתיהם הקלפים הפתוחים שכולם רואים.

**באמצע — הציוד שלי.** מה שהנחתי לפניי.

**למטה — היד שלי.** **רק אתם רואים אותה.** אחרים רואים רק כמה קלפים יש לכם.

**בצד — אני, שחקנים, יומן.** דרגה ואאורה עם כפתורי פלוס ומינוס, קובייה, שינוי מין, סיום תור.

## לחיצה על קלף

פותחת אותו בגדול עם כל האפשרויות: **שים לפניי · שים על השולחן · תן ל... · זרוק**.

קלף על השולחן של שחקן אחר — יש כפתור **קח לעצמי**, לגניבות.

## מה המשחק לא עושה

**הוא לא אוכף חוקים.** הוא לא יעצור אתכם אם תעלו דרגה בלי להילחם או תשחקו קלף בזמן הלא נכון.

**זה מכוון.** אתם מכירים את החוקים, ואתם רוצים לגלות אם המשחק כיף — לא לריב עם תוכנה.

**המסך מתעדכן כל שתי שניות** אצל כולם. אם מישהו שיחק קלף, תראו את זה מיד.
